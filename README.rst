Student Grade Statistics
=========================

This project uses Python's statistics module to calculate information about a list of student grades.

I chose the statistics module because it is simple for beginners.
It can calculate the average and median of student grades.

Installation
-------------

No installation is needed because the statistics module is already included with python.

How to run the program
-----------------------
1. Download or clone this repostitory.
2. Open a terminal in the project folder.
3. Run this command:

  python grade_statistics.py

Example outlet
--------------

Average: 86.6
Median: 88
Highest grade: 92
Lowest grade: 78
